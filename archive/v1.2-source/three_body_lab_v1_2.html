오차 기준과 근접 안전장치

G = 1인 무차원 평면 문제입니다. 적응형 적분기는 atol = rtol / 100, 최대 간격 .02를 사용합니다. 국소 오차 추정과 근접 시간척도로 간격을 조절하지만 엄밀한 오차 상한은 아닙니다.

연화가 없을 때 거리가 1e-5 이내이거나 요구 간격이 1e-12 미만이면 중단합니다. 고정 간격이 근접 운동을 해상할 수 없을 때도 중단합니다. 충돌 시 병합·반발·순간이동을 만들지 않습니다. 이는 충돌 검출의 수학적 인증이나 충돌 정칙화가 아닙니다.

실제로 계산하는 것

r̈ᵢ = Σⱼ≠ᵢ G mⱼ (rⱼ − rᵢ)
　 / (|rⱼ − rᵢ|² + ε²)³ᐟ²

세 점질량의 평면 2D 운동을 JavaScript의 64비트 부동소수점으로 계산합니다. 기본값은 G = 1, ε = 0입니다. 화면의 원 크기는 질량의 시각화일 뿐, 충돌 반지름이 아닙니다. 상대론·유한 크기·중력파는 포함하지 않습니다.

RK45는 Dormand–Prince 5(4) 쌍의 차이로 국소 오차를 추정합니다. Taylor 16은 이전 급수 재귀식을 매번 다시 전개하며, 위치 17차·속도 16차 다항식과 스텝 절반 비교를 사용합니다. 구현의 수렴반경·전역 오차는 인증하지 않습니다.

에너지 E = K + U, U = −Σᵢ<ⱼ Gmᵢmⱼ / √(rᵢⱼ² + ε²). 진단의 분모 E* = max(|E₀|, 10⁻¹²(K₀ + |U₀|), 10⁻³⁰). L₀가 0인 경우에도 정의되도록 각운동량은 절대 변화를 표시합니다.

ε > 0은 원래 중력을 바꿉니다. 충돌을 해결한 것으로 해석하지 마세요. 낮은 에너지 오차, 작은 복귀 오차, 두 방법의 일치만으로 궤도 정확성이나 일반해가 증명되지는 않습니다.

FROM APPROXIMATION TO ENCLOSURE

실제 해가 이 구간 안에 있음을 검사합니다.

두 적분기의 숫자를 비교하는 대신, 반올림과 Taylor 나머지를 모두 바깥쪽으로 감싼 구간을 계산합니다. 인증된 시간 구간과 특정 초기조건에 대한 컴퓨터 보조 증명입니다. 일반해·혼돈·주기성의 증명은 아닙니다.

시뮬레이션의 현재 시점이 아니라 t = 0 초기조건부터 인증합니다. 입력의 십진 문자열을 정확한 유리수로 해석하며 측정 오차를 가정하지 않습니다. G = 1, ε = 0만 지원합니다.

입력을 고르고 실행하세요. 기존 궤도와 기록은 바꾸지 않습니다.
왜 이것을 수치 비교가 아닌 인증이라고 하나요?

1. 산술의 포함성 — 모든 끝점은 정수 / 2¹⁹²입니다. 곱셈·나눗셈·제곱근을 정수 연산으로 바깥쪽에 반올림합니다. 화면 표시용 Number는 인증 판정에 사용하지 않습니다.

Y + [0,h] F(B) ⊂ int(B),　hL < 1

2. 존재·유일성 — 위 Picard 포함 조건과 수축 조건을 각 구간에서 검사합니다. B 안에서 모든 물체 사이 거리의 하한이 양수여야 합니다.

Y(next) ⊇ Σ(k=0…p−1) Cₖ(Y) hᵏ + Cₚ(B) hᵖ

3. 유한 Taylor 나머지 — Cₖ는 k!로 나눈 시간 미분 계수입니다. 전 구간 상자 B에서 나머지 미분을 감싸고, 다음 구간의 시작 상자로 전달합니다. 무한급수의 수렴을 추측하지 않습니다.

4. 재검사 — 증명서에는 모든 단계의 시간 간격·전 구간 상자·끝점 상자를 저장합니다. 앱은 이를 다시 계산하며, 소스 묶음에는 독립 작성한 Python 검사기도 들어 있습니다.

인증 실패, 신뢰 범위, 아직 증명하지 않은 것

실행 예산은 최대 512단계 / 768회 시도입니다. 상자를 너무 넓게 계산하거나 근접 통과를 충분히 감싸지 못하면 그 지점까지만 인증합니다. 인증 실패가 실제 충돌이나 해의 부재를 뜻하지 않습니다.

증명은 명시된 뉴턴 점질량 모델과 정확한 입력에 한정됩니다. 실제 천체 측정 오차·상대론·유한 반지름·전체 3D 초기조건은 포함하지 않습니다. Lean 등의 형식검증은 아니며, 수학적 논증·프로그램·정수 런타임의 올바름을 신뢰합니다. 정수 산술과 별도 언어 재검사로 신뢰 범위를 줄였지만 완전히 없애지는 않았습니다.

섭동 분리가 커져도 양의 무한시간 Lyapunov 지수나 혼돈은 아직 증명한 것이 아닙니다. 반올림된 8자 초기조건을 인증해도 주기궤도 존재 증명이 되지는 않습니다.
