## 가중 노름의 유도

상태 y=(r,v), 벡터장 F(y)=(v,a(r))에 대해 도함수는 블록 행렬이다.

```text
DF = [ 0  I ]
     [ A  0 ],     A = D_r a.
```

후보 상자 B 전체에서 K≥max(1,||A||∞)를 정한다. 기존 비가중 최대 노름은 hK<1을 요구했다. 새 구현은 같은 상자와 K에 대해

```text
||(δr,δv)||K = max(sqrt(K)||δr||∞, ||δv||∞)
```

를 쓴다. 두 상태 차이의 이 노름을 N이라 하면

```text
sqrt(K)||δv||∞ ≤ sqrt(K)N
||a(r)-a(r~)||∞ ≤ K||r-r~||∞ ≤ sqrt(K)N.
```

따라서 F의 Lipschitz 상수는 sqrt(K) 이하이다. K는 각 상자 전체에서 고정한다. 단계마다 노름이 달라도 단계별 존재·유일성 논증을 이어 붙일 수 있다.

기존과 같은 보수적 도함수 상한

```text
K ≥ max(1, 8 max_i Σ_{j≠i} m_j/d_ij³)
```

을 사용한다. 평면 힘 u/|u|³의 도함수 2-노름은 2/|u|³이고, 무한 노름은 √2배 이하이다. 자신의 위치와 상대 물체 위치 블록 모두 기여하므로 4√2<8은 유효한 행합 상한이다. sqrt(K)는 부동소수점이 아니라 바깥 반올림 정수 제곱근으로 계산한다.

## 단계 정리

시작 상자 Y, 전체 시간의 후보 상자 B, 정확한 h>0에 대해 다음을 확인한다.

1. B의 모든 상태에서 물체 간 거리 하한이 양수이다.
2. Y+[0,h]F(B) ⊂ int(B).
3. h sqrt(K)<1.

그러면 C([0,h],B)의 Picard 연산자는 가중 균등 노름에서 자기 사상이자 수축이다. 닫힌 상자에 값을 갖는 이 함수 공간은 완비이다. Banach 고정점 정리로 유일한 해가 B 안에 존재한다. 충돌 없는 영역의 벡터장은 매끄러우므로 다른 고전해가 같은 초기값에서 분기하지도 않는다.

끝점은 기존과 같은 유한 Taylor 나머지 정리로 감싼다.

```text
y(t+h) ∈ Σ_{k=0}^{p−1} C_k(Y)h^k + C_p(B)h^p.
```

각 성분의 나머지 중간 시각이 달라도 모두 B에 있으므로 포함이 성립한다. Euler 끝점 상자와 교차하고 다음 단계의 Y로 전달한다. 귀납 적용으로 [0,1] 전체를 인증한다. 무한급수 수렴반경을 가정하지 않는다.

높은 차수와 작은 간격도 항상 유리하지 않았다. 직사각형 구간이 상관관계를 잃는 wrapping/dependency 문제가 남아 있다. 다음은 affine/Lohner/Taylor-model 방식과 나머지 폭 제어를 검토한다. 아직 구현하지 않은 개선의 효과는 단정하지 않는다.
